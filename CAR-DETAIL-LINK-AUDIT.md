# Links to generic car detail guides: mismatch audit

Audit date: 2026-10-01

## Scope and finding

This audit covers links whose destination is one of the four localized `car-detail` pages, including links generated by `script.js`. Those pages are general vehicle-information verification guides, not individual vehicle records. The following UI locations name a particular model or promise its profile, so visitors can reasonably expect model-specific information at the destination.

## Mismatches

| Source page / location | Current label or card content | Why the destination mismatches | Recommendation |
|---|---|---|---|
| `index.html` featured vehicle cards (3 cards) | BYD Seal, Tesla Model Y, BMW 3 Series; each card is fully clickable and includes vehicle-specific type and summary | Each card named a vehicle but led to the same generic Arabic guide | **Resolved:** destination now opens the matching vehicle in the Arabic company catalog. |
| `en.html`, `fr.html`, `pt.html` localized featured cards (3 cards per page, generated in `script.js` `buildLocalizedHomeServices`) | BYD Seal, Tesla Model Y, BMW 3 Series; localized supporting description and official-source cues | Each named model card led to the same generic language-specific guide, not that model's profile | **Resolved:** cards now open the matching vehicle in their localized company catalog. |
| `en.html` featured section CTA (generated in `script.js` `buildLocalizedHomeServices`) | View all vehicle profiles | This promised a collection of profiles but opened one general guide | **Resolved:** destination now opens `models-en.html`. |
| `fr.html` featured section CTA (generated in `script.js` `buildLocalizedHomeServices`) | Voir tous les profils | This promised all vehicle profiles but opened one general guide | **Resolved:** destination now opens `models-fr.html`. |
| `pt.html` featured section CTA (generated in `script.js` `buildLocalizedHomeServices`) | Ver todos os perfis | This promised all vehicle profiles but opened one general guide | **Resolved:** destination now opens `models-pt.html`. |
| `index.html`, `en.html`, `fr.html`, `pt.html` recommendation results (generated in `script.js` `renderRecommendations`) | Per-model card heading, fit score, and “عرض الملف” / “View profile” / “Voir le profil” / “Ver perfil” link | The recommendation is personalized for a named make and model, but its profile link led to the generic guide. | **Resolved:** each link now carries the make and model to the matching localized company catalog, which opens that vehicle's reference panel. |

The language labels above are generated by the locale data in `script.js`; the Arabic strings may display incorrectly in some terminals depending on file encoding, but they are the visible UI text in the Arabic locale.

## Audited link counts and updated destination mapping

- Arabic home (`index.html`): 3 featured cards and up to 4 personalized recommendations now open `companies.html` with a model query.
- English home (`en.html`): 3 generated featured cards and up to 4 personalized recommendations now open `companies-en.html` with make/model queries; the collection CTA opens `models-en.html`.
- French home (`fr.html`): 3 generated featured cards and up to 4 personalized recommendations now open `companies-fr.html` with make/model queries; the collection CTA opens `models-fr.html`.
- Portuguese home (`pt.html`): 3 generated featured cards and up to 4 personalized recommendations now open `companies-pt.html` with make/model queries; the collection CTA opens `models-pt.html`.

Recommendation links are data-driven, so the exact four models shown can change with user preferences and catalog scores. Each now passes its own make and model to the localized company catalog.

## Similar links excluded from mismatch findings

The language switch and `hreflang` links on the car-detail pages also point to localized `car-detail` URLs, but those links promise language selection and correctly serve that purpose. The Arabic featured-section “استعرض جميع الموديلات” link in `index.html` targets the companies/catalog section, not a `car-detail` guide, so it is not part of this mismatch set.

## Implementation

The links were updated after the audit: featured cards and recommendation links now target matching vehicle entries in the localized company catalog; the “view all profiles” calls to action now target the localized models catalog. `script.js` now reads `company` and `model` query parameters and opens the matching vehicle reference panel on arrival. The generic `car-detail` guide pages remain unchanged and can still be reached through their language navigation.
